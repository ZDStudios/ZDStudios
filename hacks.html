Install Tampermonkey

Pick your browser:

  1. Open the Tampermonkey page on the Chrome Web Store.
  2. Click Add to Chrome.
  3. Click Add extension in the popup.
  4. Click the puzzle piece 🧩 in the toolbar and pin Tampermonkey.
⚠️ Go to chrome://extensions, click Details on Tampermonkey and turn on Allow User Scripts (older Chrome: turn on Developer mode top right). Otherwise scripts may not run.
  1. Open the Tampermonkey page on Edge Add-ons.
  2. Click Get.
  3. Click Add extension in the popup.
  4. Click the puzzle piece 🧩 in the toolbar and pin Tampermonkey.
⚠️ If scripts don't run, go to edge://extensions, turn on Developer mode (left sidebar) and check Tampermonkey's details for an Allow User Scripts toggle.
  1. Open the Tampermonkey page on Firefox Add-ons.
  2. Click Add to Firefox.
  3. Click Add in the popup.
  4. Click the puzzle piece 🧩 (Extensions menu) and pin Tampermonkey.
💡 Firefox is the easiest, no extra toggle needed.
  1. Brave uses the Chrome store, so open the Tampermonkey page on the Chrome Web Store.
  2. Click Add to Brave.
  3. Click Add extension in the popup.
  4. Click the puzzle piece 🧩 in the toolbar and pin Tampermonkey.
⚠️ Go to brave://extensions, click Details on Tampermonkey and turn on Allow User Scripts (older Brave: Developer mode).
